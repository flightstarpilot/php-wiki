# Configuration

All settings are stored in the `settings` table and edited from the admin
panel at `/admin.php`. The only file you edit by hand is
`config/config.php`, which is generated by the installer and contains the
database connection details and the application encryption key.

## config/config.php

This file is written by the installer and must not be committed to version
control. It returns an array:

    return [
        'db' => [
            'driver' => 'sqlite',
            'path'   => '/var/www/wiki/data/wiki.sqlite',
        ],
        'app' => [
            'key'          => '64-char-hex-string',
            'installed'    => true,
            'version'      => '0.1.0',
            'installed_at' => '2026-01-01T00:00:00+00:00',
        ],
    ];

### Database driver

`db.driver` is one of:

- `sqlite` - uses `db.path`
- `mysql` - uses `db.host`, `db.port`, `db.database`, `db.username`,
  `db.password`
- `http` - uses `db.endpoint`, `db.method`, `db.auth_type`, `db.auth_token`,
  `db.auth_header`, `db.timeout`. See
  [HTTP database protocol](http-database-protocol.md).

Changing the driver requires editing this file by hand and does not migrate
data. The Storage page in the admin panel tests the current connection but
does not switch drivers.

### app.key

A 64-character hex string used to encrypt SMTP credentials and sign
sessions. Generate a new one with:

    php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"

Rotating this key invalidates every stored SMTP password. Re-enter them in
the admin panel after rotating.

## Settings reference

### Site

| Key                 | Description                                                    |
| ------------------- | -------------------------------------------------------------- |
| `site.name`         | Site name shown in the header, page titles, and outbound mail. |
| `site.title`        | Fallback `<title>` for pages without a specific title.         |
| `site.subtitle`     | Optional subtitle.                                             |
| `site.description`  | Meta description and RSS channel description.                  |
| `site.base_url`     | Canonical URL. Leave blank to auto-detect from the request.    |
| `site.logo`         | Logo URL or inline SVG.                                        |
| `site.favicon`      | Favicon URL.                                                   |
| `site.footer`       | Raw HTML appended to the public footer.                        |
| `site.timezone`     | IANA time zone, e.g. `Asia/Shanghai`. All timestamps are stored in UTC and rendered in this zone. |
| `site.default_lang` | Default content language.                                      |
| `site.home_slug`    | Slug served at `/`. Defaults to `home`.                        |
| `site.maintenance`  | When `1`, the front end returns 503 for everyone except admins. |

### SEO

| Key                    | Description                                       |
| ---------------------- | ------------------------------------------------- |
| `seo.robots`           | Meta robots directive.                            |
| `seo.sitemap_enabled`  | Serve `/sitemap.xml`.                             |
| `seo.404_content`      | Raw HTML injected into the 404 page.              |
| `seo.404_page_slug`    | Optional slug whose content is used for 404s.     |

### Mail

| Key                | Description                                    |
| ------------------ | ---------------------------------------------- |
| `mail.enabled`     | Master switch for outbound email.              |
| `mail.transport`   | `smtp`, `sendmail`, or `mail`.                 |
| `mail.host`        | SMTP host.                                     |
| `mail.port`        | SMTP port: 465 (SSL), 587 (STARTTLS), 25.      |
| `mail.encryption`  | `ssl`, `tls`, or `none`.                       |
| `mail.username`    | SMTP username.                                 |
| `mail.password`    | SMTP password, stored encrypted at rest.       |
| `mail.from_address`| Envelope sender.                               |
| `mail.from_name`   | Display name. Supports `{site_name}`.          |

Templates live under `mail.tpl.*` and support `{site_name}`, `{site_url}`,
`{username}`, and `{link}` placeholders.

### Accounts

| Key                    | Description                                         |
| ---------------------- | --------------------------------------------------- |
| `auth.allow_register`  | Allow open registration.                            |
| `auth.invite_only`     | Require an invitation code to register.             |
| `auth.email_verify`    | Require email confirmation before login.            |
| `auth.register_review` | New accounts start as `pending` until an admin approves. |
| `auth.github_oauth`    | Enable sign-in with GitHub.                         |
| `auth.github_client_id`| GitHub OAuth application client ID.                 |
| `auth.github_client_secret` | GitHub OAuth application secret.               |
| `auth.default_role`    | Role assigned to new accounts: `user` or `editor`.  |

The GitHub OAuth callback URL is `https://your-host/auth/github/callback`.

### Features

Each of the following is `0` or `1`.

- `feature.anonymous_read` - allow browsing without an account
- `feature.comments` - comments on issues and proposals
- `feature.issues` - issue tracker
- `feature.proposals` - propose edits
- `feature.attachments` - file uploads
- `feature.history` - page version history
- `feature.backlinks` - backlink panel
- `feature.tags` - tag system
- `feature.search` - search
- `feature.fuzzy_search` - prefix matching in search
- `feature.page_lock` - per-page lock
- `feature.auto_redirect` - write a redirect when a slug changes
- `feature.rss` - RSS feed
- `feature.multi_lang` - translation groups

### Cache

| Key                       | Description                    |
| ------------------------- | ------------------------------ |
| `storage.cache`           | `none` or `redis`.             |
| `storage.redis_host`      | Redis host.                    |
| `storage.redis_port`      | Redis port.                    |
| `storage.redis_password`  | Redis password, if any.        |
| `storage.redis_db`        | Redis database index.          |

### Attachments

| Key                          | Description                              |
| ---------------------------- | ---------------------------------------- |
| `attachment.driver`          | `local` or `s3`.                         |
| `attachment.allowed_types`   | Comma-separated extension whitelist.     |
| `attachment.max_size`        | Maximum size in bytes.                   |
| `attachment.s3_endpoint`     | S3-compatible endpoint.                  |
| `attachment.s3_bucket`       | Bucket name.                             |
| `attachment.s3_region`       | Region, or `auto` for Cloudflare R2.     |
| `attachment.s3_access_key`   | Access key ID.                           |
| `attachment.s3_secret_key`   | Secret access key.                       |
| `attachment.s3_public_url`   | Public base URL for uploaded objects.    |

### Search

| Key             | Description                                         |
| --------------- | --------------------------------------------------- |
| `search.mode`   | `simple` uses LIKE; `fts` uses FTS5 or FULLTEXT.    |

### Appearance

| Key               | Description                              |
| ----------------- | ---------------------------------------- |
| `ui.theme_color`  | Primary color as a hex value.            |
| `ui.dark_mode`    | `auto`, `light`, or `dark`.              |
| `ui.custom_css`   | Raw CSS injected into every page.        |
| `ui.custom_js`    | Raw JavaScript injected into every page. |
